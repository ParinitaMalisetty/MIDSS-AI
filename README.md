# MIDSS-AI

## Municipal Infrastructure Decision Support System using Artificial Intelligence

MIDSS-AI is an AI-assisted geospatial decision support platform for smart cities. The system enables citizens to report infrastructure defects, automatically detects and assesses defect severity using computer vision, prioritizes maintenance tasks, and provides an interactive GIS dashboard for municipal authorities.

Existing municipal complaint management systems primarily function as complaint registration platforms, relying on manual inspection and prioritization, which often leads to delayed responses, inconsistent decision-making, and inefficient allocation of maintenance resources. To address these challenges, this project proposes MIDSS-AI, an AI-driven Multi-Agent Decision Support System that automatically analyzes citizen-submitted images of municipal infrastructure issues such as potholes, road cracks, garbage accumulation, drainage problems, waterlogging, and faulty streetlights using a deep learning model. The system intelligently classifies the complaint, estimates its severity, assigns an appropriate priority level, and generates actionable decision-support recommendations for municipal engineers while providing role-based dashboards for citizens, engineers, and administrators. By integrating computer vision with an agentic decision-support framework, the proposed solution aims to enhance the efficiency, accuracy, and transparency of municipal infrastructure management, ultimately enabling faster response times and smarter urban governance.
